# RoomKit — a yngcompany spatial product

RoomKit is a conceptual spatial-commerce SaaS landing page and 3D showroom builder. It explores how brands can compose interactive spaces, publish them to the web, and turn products into memorable moments.

Designed and built by **yngcompany**.

## Highlights

- Interactive 3D showroom built with React Three Fiber and Three.js
- Visual no-code builder interface with a publish-state interaction
- Responsive marketing site for a spatial-web SaaS product
- Product positioning, UI system, and front-end implementation by yngcompany

## Stack

- React + Vite
- Three.js + React Three Fiber + Drei
- CSS

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
